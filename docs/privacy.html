Privacy Policy for Superpower

Last updated: September 15, 2026

Superpower is a browser extension that connects supported AI web applications with Model Context Protocol (MCP) tools and user-configured MCP servers. This Privacy Policy explains what information Superpower may process, why it is processed, and the choices available to users.

1. Information Superpower may process

Extension settings and configuration. Superpower may store settings in Chrome extension storage, including MCP server configuration, enabled-tool preferences, interface preferences, automation delay settings, connection state, and other extension preferences required to provide the service.

MCP tool data. When a user requests an MCP tool operation, relevant tool parameters, user-provided inputs, and tool results may be processed and transmitted to the MCP server selected or configured by the user. The exact data handled depends on the MCP tools the user chooses to use.

Supported website content. Superpower reads and modifies portions of supported AI chat interfaces when necessary to display the Superpower sidebar, detect MCP tool calls, insert MCP instructions or tool results, and coordinate user-requested tool execution. Superpower does not use these permissions to monitor unrelated websites.

2. Analytics and technical information

The current version of Superpower may collect limited operational and technical telemetry to understand reliability, feature usage, and errors. Depending on the deployed configuration, this may include:

  • a randomly generated analytics identifier;
  • extension version;
  • browser and browser version;
  • operating system and operating system version;
  • device type;
  • language and region inferred from language settings;
  • timezone and timezone offset;
  • screen resolution and pixel ratio;
  • supported-site hostname;
  • MCP connection and tool execution events;
  • feature interaction and session information; and
  • error and diagnostic information.

Superpower may use Google Analytics or similar operational analytics infrastructure for this telemetry. Analytics are used for product reliability, debugging, performance, and feature improvement, not for personalized advertising, credit decisions, or lending.

3. Clipboard access

Superpower may write text to the clipboard only when the user explicitly chooses a copy action, such as copying generated MCP instructions. Superpower does not request permission to read clipboard contents.

4. How information is used

Information is processed only as needed to:

  • provide MCP connectivity and tool execution;
  • maintain extension settings and preferences;
  • insert MCP instructions and tool results into supported AI interfaces;
  • diagnose failures and security or compatibility issues;
  • measure reliability and performance; and
  • improve disclosed Superpower functionality.

Superpower does not sell user data. Superpower does not use user data for personalized advertising, creditworthiness assessment, or lending decisions.

5. Information sharing

Information may be transmitted to the following parties only when necessary for the disclosed functionality:

  • User-configured MCP servers: tool requests and related data are sent when the user invokes MCP tools.
  • Supported AI services: instructions or tool results may be inserted into the active AI chat service as part of the user-requested workflow.
  • Analytics providers: limited operational telemetry may be transmitted to providers such as Google Analytics when analytics are enabled in the deployed version.

Superpower does not sell information to data brokers, advertising platforms, or resellers.

6. Remote configuration

Superpower may retrieve configuration data, such as feature flags, compatibility settings, notifications, or supported-site adapter configuration, from remote services. These responses are treated as data. Superpower does not use remote configuration to execute remotely hosted JavaScript or WebAssembly.

7. Storage and retention

Extension configuration may be stored locally using Chrome extension storage. Users can remove locally stored extension data by uninstalling the extension or clearing extension data through browser controls. Analytics retention is governed by the configuration of the analytics service used by the deployed version.

8. Security

Where applicable, Superpower uses encrypted network protocols such as HTTPS or WSS for communications. Users are responsible for selecting and trusting the MCP servers and third-party tools they connect to Superpower.

9. User choices

Users may disconnect their MCP server, disable tools or extension functionality, remove stored extension data, or uninstall Superpower at any time. Where telemetry controls are made available in the extension, users may use those controls to adjust telemetry behavior.

10. Children's privacy

Superpower is not directed to children under 13 and is not designed to knowingly collect personal information from children.

11. Chrome Web Store Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements. Information is used only to provide or improve user-facing Superpower functionality, security, maintenance, reliability, and performance, and is not used for personalized advertising, sale to third parties, or credit-related decisions.

12. Changes to this policy

This Privacy Policy may be updated when Superpower's functionality, data practices, or legal requirements change. The revision date at the top of this page will be updated when material changes are made.

13. Contact and support

For privacy questions, support requests, or security concerns, please use the project's public support resources listed on the Superpower Support page or the official Chrome Web Store listing.
