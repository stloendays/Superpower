Superpower Support

Support information for the Superpower browser extension

Superpower connects supported AI web applications with user-configured Model Context Protocol (MCP) servers and tools. This page provides the recommended channels for support and issue reporting.

Getting help

Before reporting a problem, check that your MCP server is reachable, that the required tools are enabled in Superpower, and that the active website is one of the supported AI interfaces.

Bug reports and feature requests

Please use the Superpower GitHub repository to report reproducible bugs, compatibility issues, or feature requests:

github.com/stloendays/Superpower-V1

When reporting a bug, include the browser version, Superpower version, affected website, expected behavior, actual behavior, and reproduction steps. Do not include API keys, passwords, private MCP credentials, or sensitive conversation content.

Privacy questions

For details about information processed by the extension, see the Superpower Privacy Policy.

Security concerns

If you believe you have found a vulnerability, do not publish credentials, private data, or actionable exploit details in a public issue. Follow the Superpower Security Policy and use the private publisher contact information provided in the Chrome Web Store listing for sensitive reports.

Third-party MCP servers

Superpower can connect to MCP servers selected by the user. Problems involving a specific MCP server, external API, model provider, or third-party tool may need to be addressed by that service's operator.
