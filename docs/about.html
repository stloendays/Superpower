About Superpower

Model Context Protocol tools inside the AI web applications you already use

Superpower is a Chrome extension that connects supported AI web interfaces to Model Context Protocol (MCP) servers and tools. It is designed to reduce the friction between conversational AI and external capabilities by keeping tool discovery, execution, and returned results inside the user's existing chat workflow.

Project & collaboration

Superpower is developed as a collaborative project between the University of Oxford and the National University of Singapore (NUS). The current project is led by Tony, who drives project direction, architecture, integration strategy, and release coordination.

The collaboration focuses on practical human–AI workflows: making MCP-based agent systems easier to deploy, reducing unnecessary tool and context overhead, and improving how models discover, call, and chain external tools from familiar web interfaces.

What Superpower does

  • connects to user-configured local or remote MCP servers;
  • discovers the tools exposed by connected MCP servers;
  • lets users enable or disable individual tools;
  • generates MCP-compatible instructions for supported AI interfaces;
  • detects supported structured tool-call output;
  • routes user-requested tool calls to the configured MCP endpoint;
  • returns tool results to the active conversation; and
  • provides connection, workflow, and automation controls from a browser sidebar.

How it works

At a high level, Superpower sits between the active AI web interface and the MCP endpoint configured by the user. The extension handles the browser-side user interface and supported-site integration. The configured MCP server remains responsible for exposing and executing tools. This separation allows users to retain control over the servers and capabilities they connect.

Superpower currently supports MCP workflows over transports including SSE, WebSocket, and Streamable HTTP where supported by the configured environment.

Supported AI interfaces

The project includes adapters for a growing set of AI and developer chat interfaces, including ChatGPT, Gemini, Perplexity, Grok, OpenRouter, DeepSeek, GitHub Copilot, Mistral, Kimi, Qwen Chat, Z.ai, and other supported sites listed by the project. Third-party website changes can affect compatibility, so the supported set may evolve between releases.

Open-source foundation

Superpower V1 is a modified derivative of MCP SuperAssistant. The original MIT license and upstream attribution are preserved in the project's LICENSE and NOTICE.md files.

The current Superpower project extends that foundation with its own product direction, branding, workflow design, compatibility work, and release engineering.

Privacy and security

Superpower is designed so users remain in control of the MCP servers and tools they connect. Because MCP tools can interact with external systems, users should only connect trusted servers and review tool behavior appropriate to their environment.

See the Privacy Policy for data handling details and the Security Policy for vulnerability reporting and security guidance.
